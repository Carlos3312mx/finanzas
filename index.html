☁️ Sincronización con Google Drive

Usa tu cuenta de Google Drive para mantener tus datos sincronizados de forma automática entre tu computadora y tu iPhone.

Estado: No conectado. Configura tu Client ID para habilitar la sincronización.

¿Cómo obtener tu Google Client ID gratis? (Paso a Paso)
  1. Ve a Google Cloud Console e inicia sesión.
  2. Crea un proyecto nuevo (ej. "Mi Planificador").
  3. Ve a API y Servicios -> Pantalla de consentimiento de OAuth. Configúrala como "Externo", ingresa el nombre de la app, tu correo y agrega el alcance .../auth/drive.file (permite crear y editar sus propios archivos de Drive).
  4. Ve a Credenciales -> Crear credenciales -> ID de cliente de OAuth.
  5. Selecciona tipo de aplicación: Aplicación web.
  6. En Orígenes de JavaScript autorizados, agrega tu dirección de GitHub Pages: https://carlos3312mx.github.io.
  7. Copia el "ID de cliente" generado y pégalo arriba. ¡Listo!
